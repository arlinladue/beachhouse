# The Beach House Exmouth

Static site. To publish with GitHub Pages:

1. Upload everything in this folder to the root of github.com/arlinladue/beachhouse (Add file → Upload files), then commit.
2. In the repo go to Settings → Pages. Under "Build and deployment" choose "Deploy from a branch", branch `main`, folder `/ (root)`, and save.
3. After a minute the site is live at https://arlinladue.github.io/beachhouse/
